لا أستطيع الاتصال

  1. صفحة الخادم في اللوحة: هل حالته «يعمل»؟ إن كان متوقفًا شغّله. إن كان معلّقًا فافتح قسم الفوترة.
  2. من جهازك: ping <ip>. لا رد مع خادم يعمل يعني أن الجدار داخل النظام يمنع ICMP (طبيعي) أو أن النظام لا يُقلع.
  3. nc -zv <ip> 22. «refused» يعني أن sshd متوقف؛ «timed out» يعني أن الجدار أو fail2ban يحجبك.
  4. افتح شاشة المتصفح وتحقق من الداخل بالأوامر أدناه.
bash
systemctl status ssh --no-pager
sudo ufw status
sudo fail2ban-client status sshd
sudo journalctl -u ssh -n 30 --no-pager

إن كان عنوانك ضمن Banned IP list: sudo fail2ban-client set sshd unbanip <your-ip>. إن كان الجدار يمنع: sudo ufw allow OpenSSH.

REMOTE HOST IDENTIFICATION HAS CHANGED

متوقعة بعد إعادة التثبيت فقط. في هذه الحالة احذف البصمة القديمة: ssh-keygen -R <ip>. إن لم تكن قد أعدت التثبيت فلا تتابع الاتصال وافتح تذكرة من اللوحة.

القرص ممتلئ

bash
df -h /
sudo du -xh / --max-depth=2 2>/dev/null | sort -rh | head -n 15
sudo journalctl --disk-usage

المعتاد: سجلات متضخمة، صور Docker قديمة، أو نسخ قواعد بيانات متراكمة. التنظيف الآمن:

bash
sudo journalctl --vacuum-size=200M
sudo apt autoremove -y && sudo apt clean
docker system prune -f   # if Docker is installed

نفاد الذاكرة وحمل المعالج

bash
free -h
sudo dmesg -T | grep -i "out of memory" | tail -n 5
uptime
top -b -n 1 | head -n 15

سطر Out of memory في dmesg يعني أن النواة أنهت عملية لتنقذ النظام. الحلول بالترتيب: قلّل استهلاك التطبيق، أضف مساحة swap صغيرة، أو انتقل إلى خطة أكبر. حمل أعلى من عدد vCPU باستمرار يعني أن المعالج هو الحد.

bash
sudo fallocate -l 1G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo "/swapfile none swap sw 0 0" | sudo tee -a /etc/fstab

ما ترفقه بالتذكرة

  • اسم الخادم أو عنوانه، والوقت الذي بدأت فيه المشكلة بتوقيتك.
  • ما جرّبته من الخطوات أعلاه ونتيجته.
  • تقرير mtr من جهازك إن كانت المشكلة في الاتصال.
  • مخرجات الأوامر كنص، لا كصور شاشة.

افتح التذكرة من قسم الدعم في اللوحة مرتبطة بالخادم المعني. لا ترسل كلمات مرور أو مفاتيح خاصة في أي تذكرة.

شاشة المتصفح

جلسة على شاشة الخادم نفسها من لوحة العميل، لحالات تعذّر SSH: مفتاح مفقود، جدار مغلق، أو نظام لا يُقلع.

جدار الحماية على مستوى النظام

ufw على Ubuntu و Debian: ارفض كل شيء، اسمح بما تحتاجه، لا تغلق الباب على نفسك، وانتبه لما يفعله Docker.

مفاتيح SSH

إنشاء مفتاح ed25519 على أي نظام، إضافة مفتاح ثانٍ، استبدال مفتاح، وإعداد ~/.ssh/config.
