ما يحدث بعد الدفع

بعد تأكيد الدفع يُنشأ الخادم في المنطقة التي اخترتها: تُحجز الموارد والعنوان، تُنسخ صورة نظام التشغيل الذي اخترته في الطلب، يُكتب مفتاح SSH العام الذي أدخلته، ثم يُشغَّل الخادم ويُفحص الوصول إليه. صفحة الطلب تعرض كل خطوة بوقتها، وعند الاكتمال تصلك رسالة «خادمك جاهز».

العنوان العام (IPv4) واسم الدخول مكتوبان في صفحة الخادم داخل لوحة العميل، مع أمر الاتصال جاهزًا للنسخ. لا تُنشأ كلمة مرور، ولا تُرسل واحدة بالبريد.

أول اتصال

من Linux أو macOS أو Windows 10/11 (PowerShell أو Windows Terminal، فكلاهما يحوي OpenSSH):

bash
ssh <user>@<ip>

في أول مرة يعرض SSH بصمة مفتاح الخادم ويسأل إن كنت تثق بها. اكتب yes. تُحفظ البصمة في ~/.ssh/known_hosts، ولن يسألك مجددًا ما لم تتغيّر.

output
The authenticity of host '<ip>' can't be established.
ED25519 key fingerprint is SHA256:…
Are you sure you want to continue connecting (yes/no/[fingerprint])? yes

انتبه. إن ظهرت رسالة REMOTE HOST IDENTIFICATION HAS CHANGED في اتصال لاحق ولم تكن قد أعدت تثبيت الخادم، توقف ولا تتابع، وافتح تذكرة. بعد إعادة التثبيت الرسالة متوقعة، وحلّها في مقالة إعادة التثبيت.

أول خمسة أوامر

تحقق من أنك على الخادم الصحيح، حدّث النظام، وثبّت الأدوات التي ستحتاجها في بقية هذا الدليل:

bash
hostnamectl
sudo apt update && sudo apt full-upgrade -y
sudo apt install -y ufw fail2ban unattended-upgrades curl htop
sudo timedatectl set-timezone Asia/Qatar
sudo reboot

إعادة التشغيل بعد أول ترقية تضمن أن النواة الجديدة هي التي تعمل. انتظر نحو دقيقة ثم اتصل مجددًا. إن كان اسم الدخول غير root فالحساب يملك sudo بلا كلمة مرور.

bash
uname -r
df -h /
free -h
nproc
output
6.8.0-…-generic
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1        39G  2.1G   37G   6% /
               total        used        free
Mem:           3.8Gi       210Mi       3.4Gi
2

ملاحظة. الحجم المعروض للقرص والذاكرة يطابق اسم خطتك (مثلًا 2 · 4 · 40 تعني 2 vCPU و 4 GB RAM و 40 GB NVMe). جزء صغير من القرص مخصّص لنظام الملفات نفسه.

ما التالي

  1. التحصين الأولي: مستخدم غير root، تعطيل الدخول بكلمة مرور نهائيًا، fail2ban والتحديثات التلقائية.
  2. جدار الحماية: افتح المنافذ التي تحتاجها فقط.
  3. لقطة قبل أول تغيير كبير، ونسخة احتياطية خارج الخادم لما لا تستطيع خسارته.
