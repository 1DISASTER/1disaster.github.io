مفتاح ورمز معًا

المفتاح وحده قوي. المفتاح مع رمز من تطبيق المصادقة يحميك إن سُرق جهازك ومفتاحه معًا. يُطبّق لمستخدمك اليومي فقط، وتبقى الشاشة من اللوحة طريق الطوارئ.

bash
sudo apt install -y libpam-google-authenticator
google-authenticator -t -d -f -r 3 -R 30 -w 3

امسح رمز QR بتطبيق المصادقة واحفظ رموز الطوارئ المطبوعة. ثم:

/etc/pam.d/sshd (append)
auth required pam_google_authenticator.so nullok
/etc/ssh/sshd_config.d/20-totp.conf
KbdInteractiveAuthentication yes
AuthenticationMethods publickey,keyboard-interactive
Match User root
    AuthenticationMethods publickey
bash
sudo sshd -t && sudo systemctl reload ssh

انتبه. اختبر من نافذة ثانية قبل إغلاق جلستك. nullok يسمح للمستخدمين الذين لم يُعدّوا رمزًا بعد بالدخول بالمفتاح فقط؛ احذفها حين يكتمل الإعداد لكل المستخدمين.

حدود أضيق

/etc/ssh/sshd_config.d/30-limits.conf
AllowUsers deploy
LoginGraceTime 20
MaxSessions 4
ClientAliveInterval 300
ClientAliveCountMax 2
AllowAgentForwarding no
AllowTcpForwarding local

AllowUsers يرفض أي اسم آخر قبل فحص المفتاح. المهلتان تُنهيان الجلسات المعلّقة. تمرير الوكيل مغلق لأن خادمًا مخترقًا يستطيع استخدام مفاتيحك عبره للدخول إلى خوادم أخرى؛ استخدم ProxyJump بدلًا منه حين تحتاج القفز.

ProxyJump from your machine
ssh -J <user>@<ip> <user>@10.8.0.5
