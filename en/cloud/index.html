Questions · 04

Frequently asked questions.

What exactly do I get?

A KVM virtual machine with the resources on the plan, an NVMe disk, its own public IPv4 address, full root access, and a panel to run it from: power, reinstall, snapshots and console.

How do I get into my server?

With the SSH key you add when ordering. Once the build completes, the address and the connect command are on the server page. No password is ever created.

When do I see the price?

Before you create an account. The monthly price in Qatari riyals is on the plan card and in the order summary. While a price is unpublished, ordering stays disabled.

Is a snapshot a backup?

No. A snapshot lives on the same host and is for the moment before an upgrade or a change. An off-host backup remains your responsibility until we announce a service for it.
