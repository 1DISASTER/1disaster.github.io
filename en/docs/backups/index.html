The rule

At least one copy off the server, encrypted, taken automatically, and restored once as a test. What has not been test-restored is not a backup. The provider does not matter: any S3-compatible object storage, another server over SSH, or even your own machine.

restic: one-time setup

bash
sudo apt install -y restic
sudo mkdir -p /etc/restic && sudo chmod 700 /etc/restic

Put the repository credentials in a file only root can read. The repository password is what encrypts the backup: keep it somewhere else too, since without it the backup cannot be read.

/etc/restic/env
RESTIC_REPOSITORY=s3:https://<endpoint>/<bucket>/web1
RESTIC_PASSWORD=<long random passphrase>
AWS_ACCESS_KEY_ID=<key id>
AWS_SECRET_ACCESS_KEY=<secret>
bash
sudo chmod 600 /etc/restic/env
set -a; sudo cat /etc/restic/env > /dev/null; source /etc/restic/env; set +a
restic init
output
created restic repository 9a3c1f2e at s3:https://<endpoint>/<bucket>/web1

The backup script

Dumps the database first, then uploads the directories, keeping seven daily, four weekly and six monthly snapshots:

/usr/local/sbin/backup.sh
#!/usr/bin/env bash
set -euo pipefail
set -a; source /etc/restic/env; set +a
mkdir -p /var/backups/db
pg_dumpall -U postgres | gzip > /var/backups/db/pg.sql.gz   # or: mysqldump --all-databases
restic backup /etc /var/www /var/backups/db /home --exclude-caches
restic forget --keep-daily 7 --keep-weekly 4 --keep-monthly 6 --prune
restic check --read-data-subset=5%
bash
sudo chmod 700 /usr/local/sbin/backup.sh
sudo /usr/local/sbin/backup.sh

Running daily with systemd

/etc/systemd/system/backup.service
[Unit]
Description=Off-server backup

[Service]
Type=oneshot
ExecStart=/usr/local/sbin/backup.sh
/etc/systemd/system/backup.timer
[Unit]
Description=Daily off-server backup

[Timer]
OnCalendar=*-*-* 03:30:00
RandomizedDelaySec=15m
Persistent=true

[Install]
WantedBy=timers.target
bash
sudo systemctl daemon-reload
sudo systemctl enable --now backup.timer
systemctl list-timers backup.timer

Test the restore

Once after setup and once every few months. Restore into a temporary directory and compare:

bash
restic snapshots
restic restore latest --target /tmp/restore-test --include /etc/nginx
diff -r /etc/nginx /tmp/restore-test/etc/nginx && echo identical

Note. We have not announced an off-host backup service of our own yet. Until then the external copy is your responsibility, and this article is the way we recommend doing it.
