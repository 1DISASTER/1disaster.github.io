What it is and when to use it

The browser console is the server’s screen and keyboard as if you were sitting in front of it, shown inside the client panel. It works even when networking inside the server is broken, sshd is stopped or the firewall is closed. It opens with a short-lived grant tied to your panel session alone.

  • You lost every SSH key and need to add a new one.
  • You enabled the firewall before allowing SSH.
  • fail2ban banned you by mistake.
  • The system will not boot or stops at a disk check.

Note. The console is available in regions where it has been enabled. If the button is not on your server page, open a ticket and we assist from our side.

Logging in through the console

The console asks for a local username and password, and your server has no password by default. The supported way: restart from the client panel, press e at the GRUB menu, append init=/bin/bash to the linux line, then Ctrl+X. You get a root shell with no password.

bash
mount -o remount,rw /
# add a key, fix sshd or the firewall, then:
sync
reboot -f

A simpler alternative for next time: give your daily user a password used only at the console (password login over SSH stays disabled in sshd):

bash
sudo passwd deploy

Keyboard and paste

  • The console sends key presses, not text: pasting from the clipboard is limited, so type short commands yourself.
  • The keyboard layout in the console is the server’s (US English), so some symbols may differ from your own keyboard.
  • Ctrl+Alt+Del is sent from a dedicated button in the console, not from your keyboard.
