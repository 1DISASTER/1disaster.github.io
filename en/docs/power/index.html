What each button in the client panel does, the difference between a graceful stop and a hard cut, and what is still billed while a server is stopped.

The panel actions

  • Start: boots a stopped server. The address and disk are as you left them.
  • Stop: sends a shutdown signal (ACPI) so the system closes its services, flushes memory to disk and powers off. If the system does not respond within the timeout, power is cut.
  • Restart: a graceful stop, then a start.
  • Cut: an immediate power-off, like pulling the cable. The last resort when a system is frozen; it can leave the file system needing a check at boot.

Every action is recorded in the operation history on the server page with its time and result.

From inside the system

Restarting from inside the server is cleanest because the system chooses the moment. Shutting down from inside leaves the server stopped until you start it from the panel:

bash
sudo systemctl reboot
sudo systemctl poweroff

To see why the server last rebooted:

bash
last -x reboot shutdown | head -n 5
journalctl -b -1 -p err --no-pager | tail -n 20

A stopped server is still your server

Stopping does not stop the subscription: the disk, the address and the resources stay reserved for you, and the monthly invoice continues. To stop paying, delete the server from its page, after copying what you need off the server.
