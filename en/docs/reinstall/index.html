Erasing the disk and rebuilding the server from the original image of the system you choose, with the same address and key: what is erased, what stays, and what to do before and after.

What happens

  • The whole disk is erased and every snapshot is deleted with it. There is no undo.
  • The server is rebuilt from the original image of the system it runs now, or of another system you pick in the confirmation dialog, with the same public key you entered in the order.
  • The public address, the hostname, the plan and the subscription do not change.
  • The server host key changes, so SSH warns on the first connection afterwards.

Before you press the button

Copy what you need off the server. A snapshot does not help here because it is deleted with the disk. A quick rsync to your machine:

bash
rsync -avz --progress <user>@<ip>:/var/www/ ./backup-www/
ssh <user>@<ip> "sudo mysqldump --all-databases" > all.sql

After the reinstall

Remove the old fingerprint from your machine, then connect as on day one:

bash
ssh-keygen -R <ip>
ssh <user>@<ip>

Then repeat the initial hardening. If you reinstall often, keep a script of the steps, or your own cloud-init file to run after logging in.
