Installation

bash
sudo apt install -y postgresql postgresql-contrib
sudo systemctl enable --now postgresql
psql --version
output
psql (PostgreSQL) 16.x

Port 5432 listens on 127.0.0.1 by default, which is what you want. Do not open it in the firewall unless another server you own connects, and then allow its address only.

A database and a user for the application

bash
sudo -u postgres psql <<'SQL'
CREATE ROLE app LOGIN PASSWORD 'a long random password';
CREATE DATABASE app OWNER app;
SQL
psql "postgres://app:a long random password@127.0.0.1:5432/app" -c 'select now()'

The password goes into /etc/app/env (the systemd article), not into the code. Authentication over loopback requires a password with scram-sha-256, the default in version 16.

Settings that fit the memory

The well-known rule: shared_buffers about a quarter of memory, effective_cache_size about three quarters, and a small work_mem because it multiplies by connections. For a 4 GB server shared with the application:

/etc/postgresql/16/main/conf.d/digits.conf
shared_buffers = 1GB
effective_cache_size = 3GB
work_mem = 8MB
maintenance_work_mem = 256MB
max_connections = 60
random_page_cost = 1.1   # NVMe
log_min_duration_statement = 500ms
bash
sudo systemctl restart postgresql
sudo -u postgres psql -c "show shared_buffers"

Note. For the 8 GB plan double the first three figures; for 16 GB double them again. The log lines about queries slower than half a second are the first place to look when things feel slow.

A daily dump

bash
sudo -u postgres pg_dump --format=custom app > /var/backups/db/app-$(date +%F).dump
pg_restore --list /var/backups/db/app-$(date +%F).dump | head

The custom format is compressed and lets you restore a single table. Let the backup script from the restic article pick it up, and delete anything older than a week locally.

bash
find /var/backups/db -name "app-*.dump" -mtime +7 -delete
