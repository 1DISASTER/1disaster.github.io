Installation and keys

bash
sudo apt install -y wireguard
umask 077
wg genkey | sudo tee /etc/wireguard/server.key | wg pubkey | sudo tee /etc/wireguard/server.pub
wg genkey | tee laptop.key | wg pubkey > laptop.pub

Every device has a key pair. The private key never leaves its device; the server knows public keys only.

Server configuration

/etc/wireguard/wg0.conf
[Interface]
Address = 10.8.0.1/24
ListenPort = 51820
PrivateKey = <contents of server.key>
PostUp = sysctl -w net.ipv4.ip_forward=1; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
PostDown = iptables -t nat -D POSTROUTING -o eth0 -j MASQUERADE

[Peer]
# laptop
PublicKey = <contents of laptop.pub>
AllowedIPs = 10.8.0.2/32
bash
sudo chmod 600 /etc/wireguard/wg0.conf
sudo ufw allow 51820/udp
sudo systemctl enable --now wg-quick@wg0
sudo wg
output
interface: wg0
  public key: …
  listening port: 51820

peer: …
  allowed ips: 10.8.0.2/32

Client configuration

laptop.conf
[Interface]
Address = 10.8.0.2/24
PrivateKey = <contents of laptop.key>
DNS = 1.1.1.1

[Peer]
PublicKey = <contents of server.pub>
Endpoint = <ip>:51820
AllowedIPs = 0.0.0.0/0
PersistentKeepalive = 25

AllowedIPs = 0.0.0.0/0 sends all of the device’s traffic through the server. To connect devices to each other without the internet, use 10.8.0.0/24. Import the file in the WireGuard app, or turn it into a QR code with qrencode -t ansiutf8 < laptop.conf.

Careful. Every device gets its own key and its own address. Never reuse one configuration file on two devices.
