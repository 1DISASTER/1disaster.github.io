Sizing

Minecraft needs memory and a fast core more than it needs many cores. A 4 GB plan runs a small world and up to ten players with a 2.5 GB heap; an 8 GB plan runs twenty players and some plugins with a 6 GB heap. Always leave at least 1 GB for the system.

Installation

bash
sudo apt install -y openjdk-21-jre-headless
sudo adduser --system --group --home /srv/minecraft minecraft
sudo -u minecraft bash -c 'cd /srv/minecraft && curl -fLo paper.jar "https://api.papermc.io/v2/projects/paper/versions/1.21.4/builds/latest/downloads/paper-1.21.4-latest.jar" || true'

Take the latest download link from the PaperMC site if it has changed. The first run creates the files and stops until you accept the EULA:

bash
sudo -u minecraft bash -c 'cd /srv/minecraft && java -jar paper.jar --nogui; echo "eula=true" > eula.txt'

The systemd service

/etc/systemd/system/minecraft.service
[Unit]
Description=Minecraft (Paper)
After=network-online.target

[Service]
User=minecraft
WorkingDirectory=/srv/minecraft
ExecStart=/usr/bin/java -Xms2500M -Xmx2500M -XX:+UseG1GC -XX:+ParallelRefProcEnabled -XX:MaxGCPauseMillis=200 -XX:+UnlockExperimentalVMOptions -XX:+DisableExplicitGC -XX:+AlwaysPreTouch -XX:G1NewSizePercent=30 -XX:G1MaxNewSizePercent=40 -XX:G1HeapRegionSize=8M -XX:G1ReservePercent=20 -XX:G1HeapWastePercent=5 -XX:G1MixedGCCountTarget=4 -XX:InitiatingHeapOccupancyPercent=15 -XX:G1MixedGCLiveThresholdPercent=90 -XX:G1RSetUpdatingPauseTimePercent=5 -XX:SurvivorRatio=32 -XX:+PerfDisableSharedMem -XX:MaxTenuringThreshold=1 -jar paper.jar --nogui
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
bash
sudo systemctl daemon-reload
sudo systemctl enable --now minecraft
sudo ufw allow 25565/tcp
journalctl -u minecraft -f
output
[Server thread/INFO]: Done (8.412s)! For help, type "help"

Note. The flags above are Aikar’s flags as documented by Paper. Change Xms and Xmx together to fit your plan.

Backing up the world

bash
sudo -u minecraft tar -czf /var/backups/minecraft-$(date +%F).tgz -C /srv/minecraft world world_nether world_the_end

Ship the file off the server with the restic script from the backups article. For a clean stop before the copy: systemctl stop minecraft, then start afterwards.
