Installation

From the official Docker repository, not the distribution’s older package. The official script detects Ubuntu or Debian itself:

bash
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER
newgrp docker
docker run --rm hello-world
output
Hello from Docker!
This message shows that your installation appears to be working correctly.

Note. Membership of the docker group is equivalent to root on the server. Grant it to the daily user only.

A first Compose file

An application with a database, publishing its port on the loopback address only so the web server in the next article can sit in front of it:

compose.yaml
services:
  app:
    image: ghcr.io/example/app:1.4.2
    restart: unless-stopped
    ports:
      - "127.0.0.1:8080:8080"
    environment:
      DATABASE_URL: postgres://app:${DB_PASSWORD}@db:5432/app
    depends_on:
      - db
  db:
    image: postgres:16
    restart: unless-stopped
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: ${DB_PASSWORD}
      POSTGRES_DB: app
    volumes:
      - db:/var/lib/postgresql/data
volumes:
  db:
bash
echo "DB_PASSWORD=$(openssl rand -hex 24)" > .env
chmod 600 .env
docker compose up -d
docker compose ps
docker compose logs -f app

Docker and the firewall

Docker writes its rules into iptables ahead of ufw, so a port published on 0.0.0.0 is reachable from the internet even when ufw denies it. Two ways around it:

  1. Publish every port on 127.0.0.1 as in the file above, and put a web server in front. Simplest and recommended.
  2. Or deny external access to containers by default through the DOCKER-USER chain, and allow what you need by hand:
bash
sudo iptables -I DOCKER-USER -i eth0 ! -s 127.0.0.1 -p tcp --dport 8080 -j DROP
sudo apt install -y iptables-persistent
sudo netfilter-persistent save

Housekeeping and updates

bash
docker compose pull && docker compose up -d
docker system df
docker system prune -f
docker volume ls

Old images and containers fill the NVMe disk quietly; run prune regularly, and never remove volumes before backing them up.
