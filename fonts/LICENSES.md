The DIGITS wordmark is Chakra Petch Bold set once in the master files (tracking +100, cap height 7u); use the masters, never retype it.


`noto-kufi-arabic-700.woff2` is a static weight-700 instance of the kit's Noto Kufi Arabic variable font, made with fontTools (varLib.instancer, then subset to the Arabic ranges and basic Latin). Same outlines, same licence (SIL OFL 1.1, no reserved font name). The variable original is kept in `brand/direction-b/fonts/`.
